# EG Quincenas

App de quincenas (Parte B de sueldos) de E.G. Corrugados.
Un solo archivo (`index.html`) publicado en GitHub Pages, con los datos
guardados en una planilla de Google Sheets via Apps Script (`Codigo.gs`).

- App: https://corrugadoseg-coder.github.io/quincenas-eg/
- Planilla: `EG_Corrugados_Quincenas` (hoja `Datos`, celda A1 = JSON completo)
